# Sistema de Cadastro de Loja em C

Projeto desenvolvido durante meus estudos em Análise e Desenvolvimento de Sistemas, com o objetivo de praticar lógica de programação, manipulação de arquivos e gerenciamento de dados utilizando a linguagem C.

## Funcionalidades

- Cadastro de produtos
- Listagem de produtos cadastrados
- Busca por nome e categoria
- Edição e exclusão de produtos
- Geração automática de IDs
- Validação para evitar produtos duplicados
- Ordenação de produtos por diferentes critérios
- Armazenamento de dados em arquivo
- Exportação de dados para CSV

## Tecnologias utilizadas

- Linguagem C
- GCC
- Visual Studio Code
- Arquivos de texto e CSV

## Como executar

1. Instale o compilador GCC.
2. Baixe ou clone este repositório.
3. Compile o programa:

```bash
gcc cadastro_loja.c -o cadastro_loja
```

4. Execute o programa:

No Windows:

```bash
.\cadastro_loja.exe
```

No Linux:

```bash
./cadastro_loja
```
